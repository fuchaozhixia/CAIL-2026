# 实验与报告工作表

此文件是后续记录框架，不是已经完成的实验报告。所有真实结果需小组运行并核查。

## 问题分析

合同全文中跨段关系密集，定位和修订耦合；错误位置与实际修改位置可不同。缺失项权重最高且官方基线薄弱，但过度补写会损害精度，因此采用分类全文审查和联合复核。

## 方法

1. 保留原文、解析PID，探索合同/段落长度，确认模型上下文容量。
2. 三类各一次全文检测，避免分类混淆和遗漏，记录简短证据。
3. 联合修订，采用完整一致方案；一次修复同段多种问题。
4. 再一次全文核验，减少误报和计算链不同步。
5. 程序导出原文和类型并集，严格校验并打包。

本项目采用推理与提示设计，没有已训练或微调模型。15份初赛合同若没有标注，不应直接宣称可做监督训练。可在赛事允许的前提下额外自建合同级标注数据，再考虑训练或提示选择。

## 误差分析

每类选真阳性、假阳性、假阴性样例，记录PID、证据、修改理由。重点观察：合法简称/变更被误报、其他段已有字段仍补写、金额和比例链漏改、缺失位置选错、不同冲突方案混合。只使用赛方允许查看的数据，不记录封测合同。
