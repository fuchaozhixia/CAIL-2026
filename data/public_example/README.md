# 赛题网页公开示例

`contracts.jsonl` 从用户保存的“项目介绍”网页第一个代码块逐行提取，为原始 C001、C002 两份合同。来源和输入网页SHA256见 `provenance.json`。这些是公开说明示例，不是15份初赛测试合同。

`local_reference/` 是本项目根据公开任务规则补齐的**本地参考标注，不是官方金标准**。除了网页格式示例列出的错字、名称冲突、交付期限缺失，也包含C001第5、6段的单价×数量/总价/分期金额链问题。修订采用公开C002中的协调文本。不能直接把网页中的虚构提交格式示例当作完整gold。

可用 `python view_sample_effect.py` 查看这些公开示例上的逐段预测与本地参考对照。该小样例被用于实现和调试，得到高分也不能证明泛化能力或超过官方基线。
